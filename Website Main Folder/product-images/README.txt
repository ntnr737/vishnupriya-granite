Product image folder for Vishnupriya Granite

How to change an image:
1. Prepare a real product photo, preferably landscape 1200x800 or larger.
2. Rename it to the same filename used here.
3. Replace the file in this folder.
4. Keep index.html and this product-images folder together when uploading.
